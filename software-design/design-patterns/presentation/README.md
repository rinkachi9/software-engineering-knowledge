# Presentation patterns

Patterns that separate the user interface from the logic and data behind it.

This is a catalog section: it groups a large body of related notes inside the knowledge area. It is not a separate SWEBOK topic.

## Overview

Presentation patterns are design patterns focused on organizing and managing the structure of an application's user interface and its interaction with the underlying business logic or data. They are particularly important in applications with complex UIs, as they help separate concerns, making code easier to maintain, test, and scale.

## Reading order

1. [Model-view-controller (MVC)](model-view-controller.md): MVC is a design pattern that separates an application into three interconnected components: Model, View, and Controller.
2. [Model-view-viewmodel (MVVM)](model-view-viewmodel.md): MVVM stands for Model-View-ViewModel, a presentation pattern that separates the graphical user interface (GUI) of an application from the business logic or back-end logic.
3. [Model-view-presenter (MVP)](model-view-presenter.md): MVP stands for Model-View-Presenter.
