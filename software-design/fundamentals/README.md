# Software design fundamentals

The basic ideas of design: abstraction, coupling and cohesion, decomposition, encapsulation and the signs that a design is decaying.

This section corresponds to topic 3.1 of the [SWEBOK Guide V4.0](https://www.computer.org/education/bodies-of-knowledge/software-engineering).

## Reading order

1. [Coupling and cohesion](coupling-and-cohesion.md): Coupling is the degree to which components depend on each other, and cohesion is the degree to which the elements inside one component belong together.
2. [Design rot](design-rot.md): Design rot is the gradual decay of a software design until simple changes become slow, risky and expensive.

## Sections

- [Design principles](design-principles/README.md) (8 notes): Rules of thumb that guide design decisions toward code that is easy to understand, change and extend.
