# Computer networks and communications

Network protocols and models that software depends on, from transport protocols to HTTP.

This section corresponds to topic 16.7 of the [SWEBOK Guide V4.0](https://www.computer.org/education/bodies-of-knowledge/software-engineering).

## Reading order

1. [Transmission Control Protocol (TCP)](tcp.md): TCP is a connection-oriented protocol over an IP network.
2. [User Datagram Protocol (UDP)](udp.md): UDP is a core protocol of the Internet Protocol Suite.
3. [Hypertext Transfer Protocol (HTTP)](http.md): HTTP is a method for encoding and transporting data between a client and a server.
