# Database management

Database concepts a software engineer needs: transactions, data models, indexing and data integration.

This section corresponds to topic 16.6 of the [SWEBOK Guide V4.0](https://www.computer.org/education/bodies-of-knowledge/software-engineering).

## Reading order

1. [ACID and BASE](acid-and-base.md): ACID stands for Atomicity, Consistency, Isolation, and Durability.
2. [Change data capture](change-data-capture.md): Change data capture (CDC) detects every insert, update and delete in a database and publishes it as a stream of change events.
