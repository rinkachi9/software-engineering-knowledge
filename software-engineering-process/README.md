# Software engineering process

Software engineering process covers the activities, life cycles and improvement models by which software is developed and maintained. This knowledge area covers process fundamentals, life cycles, and process assessment and improvement.

This knowledge area follows Chapter 10 of the [SWEBOK Guide V4.0](https://www.computer.org/education/bodies-of-knowledge/software-engineering) (IEEE Computer Society, 2024). Its sections are the topics of that chapter, in the same order.

## Topics

- [Software engineering process fundamentals](fundamentals/README.md) (planned): What a software process is, how processes are defined and the standards that describe them.
- [Life cycles](life-cycles/README.md) (planned): Software life cycle models and how to choose and adapt one.
- [Software process assessment and improvement](assessment-and-improvement/README.md) (planned): Assessing the capability of processes and improving them.
