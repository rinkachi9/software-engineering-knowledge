# Software engineering professional practice

Professional practice covers the knowledge, skills and attitudes software engineers need to work responsibly and ethically. This knowledge area covers professionalism, group dynamics and psychology, and communication skills.

This knowledge area follows Chapter 14 of the [SWEBOK Guide V4.0](https://www.computer.org/education/bodies-of-knowledge/software-engineering) (IEEE Computer Society, 2024). Its sections are the topics of that chapter, in the same order.

## Topics

- [Professionalism](professionalism/README.md) (planned): Accreditation, codes of ethics, legal issues, documentation and standards for software engineers.
- [Group dynamics and psychology](group-dynamics-and-psychology/README.md) (planned): How engineers work in teams: cognition, problem solving, cooperation and dealing with uncertainty.
- [Communication skills](communication-skills/README.md) (planned): Reading, writing, presenting and collaborating as a software engineer.
